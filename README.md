# REDLINE — Portfolio expérimental

Portfolio noir et rouge avec une oie animée, trois scènes interactives et un zoom cosmique au défilement. Interface adaptée au mobile et mode de réduction des animations.

**Site :** https://redline-portfolio-test.emmanuel-galland117.chatgpt.site

## Utilisation

Ouvrir `index.html` dans un navigateur ou servir ce dossier avec un serveur statique. Aucun build ni dépendance à installer. Les polices Google Fonts nécessitent une connexion ; une police de secours est prévue.

Cette version reste un prototype visuel : noms de projets, identité et adresse de contact sont des exemples.

## Historique source

`redline-history.bundle` conserve les **15 commits originaux** du dépôt source, dont les corrections mobile et zoom, avec leurs dates, auteurs et fichiers. L'absence d'authentification Git dans l'environnement a empêché le push direct ; les fichiers visibles ici sont un instantané de la version publiée.

Pour ouvrir l'historique complet localement :

```sh
git clone redline-history.bundle redline-source
cd redline-source
git log --oneline
```

Les fichiers sont dans `dist/` dans l'historique d'origine. Dans cet instantané GitHub, ils sont à la racine pour faciliter la consultation.
